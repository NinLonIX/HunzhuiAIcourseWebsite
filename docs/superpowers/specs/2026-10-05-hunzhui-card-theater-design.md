# 魂坠自动化卡片演示设计

## 目标

把用户提供的 8 张魂坠自动化控制台截图整理为一个可浏览的单文件卡片演示，用于快速说明每个功能模块解决什么问题、能看到哪些状态，以及它们如何串成一套自动化流程。

## 内容范围

卡片顺序固定为：

1. 主界面：连接状态、当前挂机策略、房间预测和精确运行日志。
2. 自动化详情：连接、自动化开关、当前阶段、入口与配置状态。
3. 挂机统计：按策略汇总总时长、胜负、胜率、局时、宝石与逐局记录。
4. 完整地图：节点、分支、当前位置和自动路线，终端实时查看对局策略详情。
5. 宝石合成：按等级投入、保留数、可消耗数量和累计成功率，批量管理合成。
6. 护符探寻：抽取次数、材料余额、可抽数量、获得护符清单和批次统计。
7. 护符分解：职业/品质筛选、锁定与可分解数量、批量选择和预计返还。
8. 护符打孔：当前孔位、新孔形、目标护符、材料余额和算法推荐。

卡片内展示截图中可对照的短字段与代表性数字，但不捏造截图未出现的新业务结论；缺少实时数据的地方使用“截图示例”或状态说明。

## 页面结构

- 单文件 HTML，输出到 `outputs/魂坠自动化卡片演示.html`。
- 左侧叙事栏：产品名、当前步骤、简短解说、三条要点、进度指示。
- 右侧舞台：8 张 3D Coverflow 卡片，选中卡片展开详细摘要，邻近卡片缩小、降亮度并带透视。
- 顶部：功能索引按钮和当前步骤编号。
- 底部：键盘、滚轮、点击操作提示。

## 视觉与交互

- 深色终端风：`#070b12` 背景，蓝灰面板，绿色/紫色/金色状态色。
- 卡片内部用 CSS 重绘小型控制台面板、表格、流程节点和指标块，不依赖外部图片。
- 支持 `←` / `→`、鼠标滚轮、点击卡片、顶部索引按钮。
- 当前卡片的关键短语使用荧光笔划线动画；侧栏内容在切换时淡出并淡入。
- 键盘焦点可见，窄屏时舞台转为单列并保留索引导航。

## 验证标准

1. HTML 文件可直接打开或通过本地静态服务器打开。
2. 8 张卡片均可通过四种导航方式到达，顺序与内容范围一致。
3. 页面不请求项目外的本地文件，不依赖截图附件才能运行。
4. 在桌面宽屏和窄屏下无横向溢出，核心文字可读。
5. 使用浏览器打开后检查初始卡片、切换、滚轮、键盘和索引按钮。
